# 界面与交互重设计方案

状态：桌面端系统设置与需求工作台已按本方案实现，实际验证见 [界面验证记录](interface-redesign-validation.md)。

## 目标与范围

采用 Vue 3、shadcn-vue、Tailwind CSS，统一导航、表单、反馈和编辑行为。保留现有数据库与 API 契约，单人使用范围不增加账号、权限、租户或协作功能。模型 API Key 仍由后端加密保存，前端只在当前编辑表单内存中短暂持有新密钥。

## 信息架构

采用共享应用外壳：固定侧栏、顶部路径与运行状态、主内容区。侧栏包含需求项目、新建项目、最近项目，以及系统设置下的接入平台和模型配置。设置拥有独立 Hash 路由 `/settings/platforms`、`/settings/models`，原 `/workspace?project=...` 项目链接继续有效。

从工作台到设置、项目切换、浏览器返回都经过路由离开保护。明确放弃后才离开；保存或生成期间阻止离开。本轮只考虑桌面端，侧栏始终固定，不实现移动端导航或移动端专项适配。

## 视觉规范

以中性灰、白色内容面板和深色主按钮为基础，靛蓝只用于品牌和选中导航。绿色表达已确认或当前启用，琥珀色表达待确认或未保存，红色用于错误与删除。正文 14px，说明 12–13px，页面标题 26–30px；统一边框、8–12px 圆角和 4px 倍数间距。避免大量背景块与装饰性文案，优先通过排版和留白建立层级。

主要动作每个区域一个；次要动作使用描边或文字按钮。每项控件具备标签、禁用和焦点状态。状态同时包含文字，不能只靠颜色辨认。

## 系统设置优先改造

### 接入平台

页面显示平台数量、搜索框、平台目录及新增按钮。目录展示名称、协议、接入地址、关联模型数量和操作。新增/编辑进入右侧 Sheet 抽屉，表单滚动区与底部保存区分开。抽屉关闭、ESC、切换设置页面都保护未保存输入。关闭后清空编辑对象，跨页面不保留另一种对象的表单。

关联模型的平台不能删除，界面展示原因，后端仍做最终校验。带有模型密钥的平台修改协议或地址时显示现有约束，不主动清除密钥。

### 模型配置

顶部显示当前生效的模式与模型；明确区分运行设置和模型目录。选择本地联调或真实模型后点击应用才生效。目录展示名称、所属平台、API 模型标识、密钥状态、启用状态和操作，可按名称/标识/平台搜索。

模型新增/编辑使用独立 Sheet，平台选项来自数据库。密钥不回显，留空保留同平台已有密钥；清除密钥需要明确勾选。保存、测试连接、应用运行选择三个动作独立。测试结果在表单内展示，测试不保存。启用中的模型不能删除；引用限制在按钮附近解释。

目录冲突保留输入并禁止继续覆盖，只提供明确重载路径。重载仍经过未保存保护。错误留在相关页面/抽屉，成功使用轻量通知；所有消息按纯文本展示。

## 需求工作台后续改造

新建页采用集中式表单，显示当前生成来源、名称、业务输入与字数，生成成功后打开已经保存的项目。示例只填空白输入。生成过程有明确忙碌状态，失败保留输入。

项目页顶部显示项目名称、版本、初始来源、确认进度和保存状态。保存评审、下载已保存 PRD 固定在顶部操作区。原有六个业务区域保留：需求评审、澄清问答、设计建议、已保存 PRD、版本历史、原始输入。

需求评审以编号卡片组织正文、来源和确认状态，支持筛选全部/待确认/已确认。背景与目标单独成区。修改已确认正文会撤销确认，并保留既有“先保存为待确认，再确认”的业务规则。删除人工需求只是编辑副本操作，保存时才提交。

澄清问题、设计建议和正式需求维持各自数据边界。接受建议保存后才形成待确认需求；已接受建议不可再次改写。PRD 和历史为只读纯文本，只展示已保存快照；未保存编辑不会混入导出。历史默认读取版本列表，可选择版本查看，不覆盖当前编辑。

## 实现结构

shadcn-vue 组件源码保存在 `frontend/src/components/ui/`，通过官方 CLI 按需引入。业务组件不仿造 UI 库；共享确认弹窗、通知和应用外壳维护稳定契约。基础组件使用官方 Reka UI 交互原语处理焦点、键盘和弹层。

`AppShell` 承担全局导航与公开项目列表；`SystemSettings` 承担目录事务副本和抽屉；`Workbench` 保留项目编辑、确认和版本流程；接口继续集中于 `src/api/`。清理 Element Plus 依赖、样式与弹窗，避免两套组件体系混用。

## 验收要求

- 系统设置：独立链接刷新、搜索、平台/模型 CRUD、抽屉保护、运行选择、连接测试不保存、密钥不回显、引用限制、并发冲突保留输入。
- 工作台：打开历史项目、新建草稿、编辑/确认/保存、问答、建议、只读 PRD 与版本、下载、路由离开保护。
- 全局：桌面布局可用，键盘进入/离开抽屉、ESC 保护、错误和空状态清楚；不直接渲染外部 HTML。移动端不在本轮范围。
- 执行前端测试、构建、后端相关测试与单 JAR 打包；浏览器验收不调用付费模型，持久化测试使用隔离数据库或已有隔离测试。
