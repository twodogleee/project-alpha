# 桌面界面重设计验证记录

验证日期：2026-10-12。范围为单人使用的桌面系统设置与需求工作台；移动端不在本轮范围。

## 实现结果

先形成 [界面设计方案](interface-redesign-design.md)，再依次改造系统设置和需求工作台。采用 shadcn-vue 官方 CLI 生成并纳入仓库的组件源码、Reka UI 交互原语及 Tailwind CSS；移除 Element Plus 依赖和旧设置弹窗。

系统设置改为接入平台、模型配置两个独立路由页面，新增和编辑使用右侧抽屉。工作台采用共享侧栏、固定保存操作区、需求卡片、状态筛选和评审进度，保留六个业务区域及既有确认、保存、版本规则。数据库与后端 API 契约未因本轮界面改造改变。

## 浏览器实际验收

浏览器验收使用随机 `alpha_model_smoke_<UUID>` PostgreSQL schema、独立测试主密钥和本机 HTTP 模拟平台。测试凭证为无真实权限的模拟字符串，未请求付费模型。模拟输出明确说明内容来自本机模拟平台。

实际执行并观察：

1. 接入平台与模型配置独立导航、直接访问及刷新；切换到模型页面后不存在平台编辑表单。
2. 平台新增、名称编辑；新平台出现在模型所属平台下拉中；搜索匹配及无结果状态。
3. 模型新增、未保存表单连接测试；测试成功后只读检查目录版本和模型列表没有改变。
4. 保存模型后仍为本地联调；显式应用真实模式与模型后才启用。编辑时 API Key 不回显，留空改名后连接测试仍成功。
5. 抽屉关闭和 ESC 触发未保存提示；继续编辑保留输入。工作台路由切换提示同样保留未保存正文。
6. 两窗口修改目录，旧窗口保存得到冲突；编辑内容保留，保存和测试被禁用，重载需要明确放弃编辑。
7. 带密钥平台的协议和地址不可直接修改；有关联模型的平台删除受限。模型删除确认后取消，目录未改变。
8. 经真实客户端与 Graph 请求本机模拟平台生成并保存草稿，再编辑、确认、保存；已确认正文修改后撤销确认，并需先保存再重新确认。
9. 回答澄清问题、保存新版本；历史版本查看不覆盖当前副本；实际下载 v1 PRD，当前项目最终保存至 v5。
10. 需求筛选待确认时显示空状态，返回全部后原已确认需求仍存在；确认进度与回答计数一致。
11. 运行最终单 JAR，直接访问系统设置与项目路由并刷新，数据库目录和 v5 项目正常读取。

只读数据库检查确认测试目录最终 revision=7、mode=demo；已保存凭证为 `v1:` 密文，不包含模拟明文。测试主密钥权限为 0600。开发库仅作只读检查，本轮未向开发目录写入测试平台、凭证或需求。

## 验证边界与清理

浏览器未请求真实厂商服务，因此未验证真实账号权限、厂商网络或模型效果。实际删除及服务端引用拒绝由集成测试覆盖；本次浏览器只验证删除确认与取消。设计建议本次为模拟输出空列表，接受建议流程依靠现有后端测试和保留的业务逻辑验证。浏览器原生刷新关闭提示未单独操作验收，路由离开与抽屉关闭保护已实际验证。

测试完成后关闭本轮创建的临时服务和浏览器标签，并删除本轮随机验收 schema；下载的模拟 PRD 归档到临时验收目录。未执行 Git add、commit、push 或部署。
