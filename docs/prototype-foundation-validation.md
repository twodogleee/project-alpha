# 原型 P1 模板与 P2 构建预览基础

日期：2026-10-29。作者：Andersen。

本记录对应 [第一阶段设计](prototype-phase-one-design.md) 的 P1/P2：固定 Zero 管理端模板、可信样板、隔离构建、浏览器验证、不可变静态产物和独立预览。这里的样板不来自模型，不创建业务原型任务、PRD 来源快照或人工确认记录。后续实现分别见 [P3 业务持久化](prototype-persistence-implementation.md) 和 [P4 模型生成](prototype-generation-implementation.md)；P5–P6 继续按设计实施。

Zero 正式来源已通过技能规划器核验为 `origin/master` 的 `6e07bd5a78804b26ad2904c151e2bf3470631c4c`，发布元数据 `zero-v3.2.1`。具体采用文件和摘要见模板 `zero-source.json`，裁剪和替换规则见 `ZERO_OVERRIDES.yml`。Alpha 工作台没有整体加入 Zero 基线。

模板保留真实表格、查询、CRUD、只读详情、反馈及必要依赖，使用独立启动入口、内存状态和静态导航。不使用 Zero OAuth、账号门户、真实菜单、HTTP 接线或环境文件。对应后台与认证接口要求属于关闭的接线范围，不宣称完整 Zero 前后端兼容。

## 本地使用

需要 Node.js 22+、npm 和可用的 Docker Linux 容器运行环境。从根目录执行：

```bash
npm run prototype:install
npm run prototype:test
npm run prototype:doctor
npm run prototype:prepare
npm run prototype:build
npm run prototype:preview
```

首次 `doctor` 在尚未准备工具链时会返回非零状态和具体原因；这不是自动安装入口。`prepare` 拉取固定版本的官方 Playwright 基础镜像，解析不可变 digest，安装锁定依赖并保存具体工具链镜像 ID。首次准备需要联网，模板或平台执行器变化后需要重新准备。

`build` 只处理 `zero-admin@1` 的可信本地样板，必须与已准备模板摘要一致。构建步骤没有模型接入、任意工程路径或 shell 命令输入。模板自身 `npm run build` 是开发者维护可信模板的验证命令，不能作为以后模型代码的宿主执行后门。

预览命令打印包装页和独立窗口入口，默认端口为 `18181`、`18182`；Ctrl+C 只停止本次服务。会话默认 15 分钟后失效，重新启动预览可获得新入口。URL 中的随机值仅限本次本地预览，不是 Alpha 身份凭证。

## 样板能力

样板在独立管理端壳中展示人员管理，使用固定模拟人员、部门和状态。支持查询、重置、分页、新增弹窗、编辑抽屉、只读详情、取消和未保存保护，以及空数据、加载、失败情景。页面文字明确标记“本地模板联调，未调用大模型”。

新增和编辑修改同一内存实体集合；详情与列表使用相同 ID 和数据。重载或重置恢复种子，不写入 PostgreSQL、浏览器持久化存储或业务接口。样板中的字段规则是模板校准材料，不自动成为后续产品的需求。

## 执行边界

构建容器通过确切 image ID 启动，采用非 root、只读根文件系统、关闭网络、去除 capabilities、禁止提权以及 CPU、内存和进程限制。任务只读挂载其输入，不挂载仓库、宿主私有配置、Docker socket 或可写宿主输出目录。

编译和浏览器操作在容器有容量限制的临时空间完成。产物通过有界结果协议返回，宿主重新校验路径、类型、字节数和 SHA-256 后封存；不从未知压缩包直接解压到宿主。超时、输出超限或执行失败会清理本任务容器，不影响其他容器。

P2 固定样板的单任务执行总上限为 5 分钟，编译和浏览器各 120 秒；后续 P4 的模型任务预算独立实现。静态产物上限 50 MiB，截图合计 20 MiB，进程结果总量有硬限制。检查失败不发布当前预览。

本机只允许一个构建执行槽。正常结束或失败会释放；强制结束宿主进程后遗留的 `execution.lock` 不自动抢占，命令会报告中断或忙碌状态。恢复前需要核对 `owner.json` 指向的进程和 `alpha-prototype-*` 容器，确认该次执行已结束后再清理对应遗留锁并显式重试，不能批量停止其他 Docker 容器。

## 预览边界

预览外壳与静态内容使用不同源。业务页面只在 `allow-scripts` 的 opaque-origin sandbox 中运行，不开放父窗口存储或同源能力；静态模块资源使用无凭证 CORS。CSP 限制脚本来源、网络、子框架、表单、Worker 及其他外部资源。

只有合法短期会话才能读取固定修订；每次页面或资源请求检查撤销、到期和 `isAvailable` 回调，父对象状态变化可拒绝后续请求。P2 是本地样板，默认资格为可读；P3 接入时必须由业务服务实现该回调，不能把默认值称为数据库权限校验。

独立窗口也使用平台包装页。内层 HTML 必须以 iframe 方式加载，直接顶层打开内层地址被拒绝，避免绕过外层导航限制。跨窗口消息校验来源窗口、opaque origin、会话、修订、消息类型和字段白名单。

预览服务启动时将允许的静态文件读为有界内存快照，磁盘后续变化不会改变正在显示的修订。已加载内容不能从浏览器内存收回，撤销影响后续访问。

## 文件存储与后续接入

`data/prototypes/` 已被仓库规则忽略，保存工具链记录、任务临时区、封存产物和 `current.json`。封存产物包含源码、静态资源、检查记录及截图；当前指针只在整个构建验证成功后原子切换。

读取当前产物时重新核对清单与实际文件。缺失、损坏或被修改时拒绝预览，不静默选择其他版本。失败候选不会覆盖旧指针。这里的指针只是 P2 本地验证入口，P3 会以数据库的原型聚合和修订引用接管业务状态。

本轮未修改业务数据库、Java 接口和 Alpha 工作台入口，未执行数据库迁移，也未调用付费模型。
